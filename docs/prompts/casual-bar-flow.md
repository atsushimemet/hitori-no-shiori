Motion / Anime.js の利用

この実装では、Motion または Anime.js を必ず使ってください。

推奨は Motionです。

会話UIで使う動き

* AIメッセージがふわっと表示される
* ローディングが静かに表示される
* /casual-bar 遷移前に会話UIが少しフェードアウトする

/casual-bar ページで使う動き

* ページ全体がふわっと表示される
* バーカードが1枚ずつ少し遅れて表示される
* カードhover時に少しだけ浮く
* 派手な動きではなく、静かで上品な動きにする

使用候補：

* motion.div
* AnimatePresence
* variants
* layout
* staggerChildren

Anime.jsを使う場合は、カード表示時のstaggerや、遷移時の控えめなローディングに使ってください。

注意点

* 実際のLLM API連携は不要
* tokyo-casual-bar への実際の接続も不要
* /stations/ebisu から取得する処理はまだ実装しない
* 現時点ではモックデータでよい
* 将来的に外部サイトやAPIから取得しやすいように、バー情報は lib/mockBars.ts に分離する
* 文字量は増やしすぎない
* 世界観は「ひとりの栞」に合わせて、静か・余白・文学的・上品にする
