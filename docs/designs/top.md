# トップページの目的
初回訪問者に、気分から”今日のあなたのひとり時間の栞”を提供することが伝わること。

## ファーストビュー
1. トップページにアクセスすると栞が栞を構成する線一つ一つを組み立てて最終的にアイコンとして表示される。
2. 表示されたアイコンは画面上にボヤッと表示されて消える。
3. テキストボックスが表示される。
4. テキストボックス内に今日の気分を示す一文がタイプライターで表示される。e.g. 仕事から離れて喫茶店で本を読みたい。
4.1. 一文は10つ登録されているタイプライターを表示する。
4.2. 最後の一文が表示された後、最初の一文に戻る。
5. テキストボックスの下にCTAである「ひとり時間をAIと探す」ボタンを設置する。
