現在の /casual-bar ページのアニメーションを、一般的な fade / slide / stagger ではなく、「ひとりの栞」独自の体験に作り替えてください。

目的

ユーザーが目にしたことのないような、しかし「ひとりの栞」の世界観に自然に合うモーションを実装してください。

求めているのは、よくある以下のような動きではありません。

* カードがふわっと表示されるだけ
* 下からスライドするだけ
* hoverで少し浮くだけ
* 一覧がstaggerで順番に出るだけ

これらは使ってもよいですが、主役にしないでください。

実装したい独自モーション

「栞スキャン・リビール」という演出を実装してください。

/casual-bar ページに遷移すると、生成りのページ上に細い栞のような光 / 紙片が現れます。

その栞がカード一覧の上を静かに通過し、栞が通った場所からバーのカード情報が浮かび上がるようにしてください。

イメージ：

1. 最初は余白のある生成りのページ
2. 細い縦長の栞がすっと現れる
3. 栞が左から右、または上から下へ静かに滑る
4. 栞が通過した場所だけ、カードの輪郭・文字・区切り線が現れる
5. 最後に栞がページの端、または見出し横に小さく収まり、一覧が完成する

これは「検索結果が表示された」のではなく、
「今日のひとり時間のページに、栞が挟まれた」
と感じられる体験にしてください。

モーションの印象

* 静か
* 上品
* 文学的
* 少し不思議
* ありきたりではない
* AIが候補を見つけている感じ
* 本のページを開いている感じ
* 栞が時間を選び取っている感じ

実装方針

Motion または Anime.js を必ず使ってください。

推奨は Motion です。
ただし、栞のスキャン線や区切り線の描画には Anime.js を使っても構いません。

使ってほしい表現

* clip-path によるカードのリビール
* mask-image またはグラデーションマスクによる、栞が通過した箇所だけ見える表現
* filter: blur() からの復帰
* 細い栞バーの移動
* カード内の文字が、栞の通過後に少し遅れて現れる
* 区切り線が栞に合わせて伸びる

具体的な動き

ページ初期状態

カードは存在しているが、まだ読めない状態にしてください。

例：

opacity: 0
filter: blur(8px)
clip-path: inset(0 100% 0 0)

または、カードの輪郭だけが薄く見えていても構いません。

栞スキャン

細い縦長の栞バーを作成してください。

見た目：

* 幅：10〜16px
* 高さ：カード群より少し長い
* 色：珈琲色、くすんだブラウン、淡いネイビーのいずれか
* 角丸
* 影はごく薄く
* 強い発光は禁止

動き：

* 左から右へ静かに移動
* または、ページ上部から下部へ静かに移動
* 移動時間は 900〜1400ms
* ease は [0.22, 1, 0.36, 1] のような上品なもの

カードリビール

栞が通過するタイミングに合わせて、カードを表示してください。

例：

clip-path: inset(0 100% 0 0) → inset(0 0% 0 0)
opacity: 0 → 1
filter: blur(8px) → blur(0px)

3件のカードは単純なstaggerではなく、
栞が通った順番に発見されるように表示してください。

文字の出方

カードの外枠が出たあと、文字情報は少し遅れて表示してください。

順番：

1. バー名
2. 最寄り駅
3. 雰囲気
4. 席・空間
5. Google Map / SNS

一気に全部出さず、ページが整っていく感じにしてください。

最後の余韻

スキャンが終わったら、栞バーは消さずに、見出し横またはページ左端に小さな栞マークとして残してください。

これは「このページは、あなたのために選ばれた栞である」というサインです。

reduced motion対応

prefers-reduced-motion に対応してください。

動きを減らす設定の場合：

* スキャン移動を行わない
* カードは短いフェードで表示する
* blurとclip-pathは使わない、または最小限にする
* 栞マークのみ静的に表示する

禁止事項

* よくあるカードstaggerだけで終わらせない
* 派手なパーティクルを使わない
* 強いグローやネオン表現にしない
* 大きな回転やバウンドを使わない
* アニメーションが主張しすぎて情報が読みにくくなる状態にしない
* ローディングスピナーのような表現にしない

完了条件

* /casual-bar ページで、栞がカードを発見していくような独自モーションがある
* カードが単にfade / slide / staggerで出るだけではない
* 「ひとりの栞」の世界観に合っている
* 栞バーが通過した後にカード情報が現れる
* 最後に栞が小さな印として残る
* Motion または Anime.js を利用している
* reduced motionに対応している
* TypeScript / lint エラーがない
