現在の Next.js プロジェクトをベースに、ファーストビューのテキストボックス内で、10個のプロンプト例がタイプライター表示されるアニメーションを実装してください。
# 目的
トップページに訪れたユーザーに、
 「このくらい曖昧で個人的な気分を入力していい」
 と自然に伝えることが目的です。
これは単なる placeholder ではなく、
 “今日のひとり時間の相談が始まる入口”として見えるようにしてください。
# 表示するプロンプト例
以下の10個を順番にタイプライター表示してください。
仕事から離れて、静かな喫茶店で本を読みたい
買う本を決めずに、本屋さんをゆっくり歩きたい
雰囲気のいい欧風カレー屋さんで、ひとりの食事を楽しみたい
気張らないカジュアルなバーで、一息つきたい
自分が一生着ていられる古着に出会いたい
休日の午前中に、作業がはかどる場所へ行きたい
考えごとを整理できる、静かな夜の過ごし方を知りたい
少し落ち込んでいるので、自分を甘やかせる場所に行きたい
新しいアイデアが浮かぶような、本屋と喫茶店を巡りたい
何も予定を決めずに、ひとりで気持ちよく散歩したい
# アニメーション仕様
テキストボックス内に、上記の文章をタイプライター風に表示してください。
流れ：
1文字ずつ表示する
文章が完成したら少し待つ
1文字ずつ削除する
次の文章を表示する
10個目まで表示したら、1個目に戻ってループする
# タイミング目安
以下を基準にしてください。
1文字表示：40〜70ms
完成後の待機：1200〜1800ms
1文字削除：20〜40ms
次の文章に移る前の待機：300〜500ms
全体として、急かされず、静かで心地よいテンポにしてください。
# Motion / Anime.js の使い方
## Motion
Motion / Framer Motion は、以下に使ってください。
テキストボックスの初回表示
focus時の軽い浮き上がり
CTAボタンのhover / tap
カーソルの点滅
入力欄周辺の余白や影の微細な変化
使用例：
motion.div
motion.form
motion.button
AnimatePresence
useReducedMotion
## Anime.js
Anime.js は、タイプライター文字そのものに使ってもよいですが、React state と相性が悪くなる場合は無理に使わなくて構いません。
使う場合は、以下のような補助演出に限定してください。
カーソルの点滅
テキストボックスの薄い罫線がゆっくり呼吸する演出
プロンプト切り替え時の小さな余韻
初回表示時のごく控えめな stagger
ただし、文字列の管理は React の state / custom hook で実装することを推奨します。

## TypewriterText.tsx
役割：
useTypewriter から現在の文章を受け取る
テキストボックス内に表示する
末尾に点滅カーソルを表示する
実際の入力と混同しないよう、placeholder的に見せる
## PromptBox.tsx
役割：
Claude Desktop のような対話開始用テキストボックスにする
内部に TypewriterText を表示する
ユーザーがクリック・focusしたら、実際に入力できそうに見える
まだ実際のAI連携は不要
## HeroCTA.tsx
ボタン文言：
「ひとり時間をAIと探す」
動き：
hoverで少しだけ浮く
tapで軽く沈む
影は強くしすぎない
# 見た目の要件
テキストボックスは大きく、余白を広く
Claude Desktop の入力欄のように、自然に対話が始まりそうな見た目
角丸は大きめ
背景は生成り、白、薄いベージュ系
文字色は深いグレー
カーソルは細く、静かに点滅
派手なグラデーションや強い発光は禁止
文字は詰め込みすぎない
主役は、タイプされていく一文と余白
# reduced motion対応
prefers-reduced-motion に対応してください。
ユーザーが動きを減らす設定の場合：
タイプライターの1文字ずつ表示は行わない
文章を一定時間ごとにフェード切り替えする
カーソル点滅は停止、または控えめにする
# 注意点
文字列が空になった瞬間にレイアウトが揺れないようにする
テキストボックスの高さは固定、または十分なmin-heightを設定する
スマホでも文章が読めるようにする
長い文章は自然に折り返す
日本語の文字切り出しは Array.from(text) を使い、絵文字や合成文字にもできるだけ対応する
setIntervalではなく、setTimeoutを使って速度を段階ごとに変えやすくする
cleanupを必ず行い、メモリリークを防ぐ
TypeScriptで型エラーが出ないようにする
npm run lint が通るようにする
