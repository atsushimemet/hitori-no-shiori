# サービス概要
「ひとりの栞」は、今の自分に必要な“ひとり時間”を提案するWebサービスです。ユーザーは店名やジャンルから探すのではなく、今の気分や目的を入力します。喫茶店、本屋、食事処、バー、作業に向いた場所などから、ひとりで幸せに過ごすためのプランを提案します。目的は、店探しではありません。自分に戻り、夢へ少し進むための時間を作ることです。

# サービス名
ひとりの栞

# トンマナ
このサイトは純喫茶のようなイメージとBRUTUSの雑誌を開いたようなワクワク感を最適なバランスで提示することで、ユーザーに対して心の中のワクワク感と静かな集中を促します。

サイト全体を通じて、文字量を極限まで少なくしてください。説明しすぎず、短い言葉と余白で伝えてください。1セクションにつき、見出しは短く。本文は1〜2文まで。カード内の文章も最小限にしてください。情報量よりも、静けさ・余白・直感的な理解を優先してください。
